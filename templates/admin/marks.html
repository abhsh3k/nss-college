Import marks from a CSV file

Every upload is filed under Semester {{ sel.semester }} as {% if sel.kind == "university" %}the university exam{% else if sel.kind == "internal" %}the internal exam{% if !sel.exam_name.is_empty() %} — {{ sel.exam_name }}{% endif %}{% else %}{{ sel.assessment }} coursework{% endif %}, keyed by {% if sel.kind == "university" %}PRN{% else %}admission number{% endif %}, and only this semester's courses are accepted. Nothing is filed straight away: both shapes land on a review page first, where each course's maximum marks is set. The Name column is only a label to read back — the PRN/admission number is what is matched against the database.
